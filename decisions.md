# Key Decisions

This file records only the decisions that matter for judging and future maintainers.

## 1. Deterministic Rules Before AI

The task queue is generated by deterministic TypeScript rules before Gemini sees anything. Gemini explains and summarizes grounded state; it does not invent operational facts.

Why this matters: judges can verify repeatable logic, unit tests can cover priority math, and the app still works when Gemini is unavailable.

## 2. Lower Priority Number Means Higher Urgency

Priority `0` or `1` is more urgent than priority `30`.

The ordering is:

```text
crowd crush risk -> urgent escort -> high incident -> gate rebalance -> medium/low incidents
```

## 3. Accessibility Escort Priority

Escort urgency is based on need type and waiting time:

```text
base 20
- wheelchair/visual urgency
- elderly/cognitive urgency
- waiting > 10 minutes
- waiting > 20 minutes
floor 8
```

The floor lets the worst escort outrank many operations tasks without always beating crowd-crush reroutes.

## 4. Gate Rebalance Does Not Beat Life Safety

Gate delays are important, but they should not outrank severe safety signals. Gate rebalance tasks have a floor of `21`.

## 5. Firestore Is Used For Operational State

The deployed app persists:

- fan escort requests
- task lifecycle state
- task snapshots

The same code falls back to an in-memory store when GCP credentials are absent, so local evaluation still works.

## 6. Demo Starts With Meaningful Pressure

A fresh deployment seeds realistic operational pressure so judges see useful behavior immediately. This avoids an empty dashboard while still making clear that data is simulated.

Seeded examples include:

- critical crowd reroute
- gate delay
- accessibility escort
- medical response

## 7. Same-Origin Cloud Run Deployment

The React app and API are served from the same Cloud Run origin. This avoids a CORS-heavy split deployment and makes judging simpler: one URL contains the full demo.

## 8. Honest Security Tradeoff

The app keeps `script-src 'self'`, but allows `style-src 'unsafe-inline'` because the current React UI uses inline style attributes. This is documented as a future hardening task rather than hidden behind an inaccurate claim.

## 9. AI Evidence Is Returned In The API

AI routes return the normal UI fields plus:

- `factsUsed`
- `taskIds`
- `recommendedActions`

This makes the AI analysis inspectable for judges and reduces the chance that the copilot is judged as a generic chatbot.
